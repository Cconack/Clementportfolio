
# Clementportfolio

A personal portfolio showcasing my work, experience, and projects in product design and digital experiences.

## Getting Started

First, install the project dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

You can start editing the application by modifying the files in the `app` directory.

## Built With

- Next.js
- React
- TypeScript

## Deployment

The project can be deployed using [Vercel](https://vercel.com/).

For more information, see the [Next.js documentation](https://nextjs.org/docs).
